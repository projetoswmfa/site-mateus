# Landing page Bravky

Abra `index.html` em um navegador ou use um servidor local nesta pasta:

```bash
python3 -m http.server 8000
```

Depois acesse http://localhost:8000.

## Arquivos
- `index.html`: estrutura, CSS e JavaScript das interações, carrossel, botões e animações.
- `desktop.svg` e `mobile.svg`: artes exportadas do Figma com animações embutidas.
- `portfolio/`: oito artes do carrossel, otimizadas para web.

O design visual de cada versão ainda está em um SVG completo. Para editar os elementos dessa arte individualmente, faça a alteração no Figma e exporte novamente. Os controles implementados em HTML podem ser editados diretamente na IDE.
